## はじめに

Happy Hacking Keyboard（HHKB）は、プログラマーやライターに愛される60%キーボードです。コンパクトな設計ゆえに、Fnキーとの組み合わせで多くの機能を実現します。

この記事では、HHKBを使いこなすために必要なショートカットキーを完全網羅してチートシートとしてまとめました。

## HHKBレイアウトの特徴

HHKBは一般的なキーボードと以下の点が異なります：

- **Escキー**: 通常の`~`/`` ` ``キーの位置（vi/vimユーザーに最適）
- **Ctrlキー**: CapsLockの位置（Sun配列と同様、ホームポジションから近い）
- **Delキー**: `\`/`|`キーの位置（DIPスイッチでBackspaceに変更可能）
- **矢印キー・F1〜F12など**: Fnキーとの組み合わせで入力

## Fnキー組み合わせ（基本操作）

HHKBの真骨頂はFnキーとの組み合わせです。キートップの前面に印字された機能がFn+キーで使えます。

### ファンクションキー

| キー | 操作 |
|------|------|
| `Fn` + `1` | F1 |
| `Fn` + `2` | F2 |
| `Fn` + `3` | F3 |
| `Fn` + `4` | F4 |
| `Fn` + `5` | F5 |
| `Fn` + `6` | F6 |
| `Fn` + `7` | F7 |
| `Fn` + `8` | F8 |
| `Fn` + `9` | F9 |
| `Fn` + `0` | F10 |
| `Fn` + `-` | F11 |
| `Fn` + `=` | F12 |

### カーソル移動・ナビゲーション

| キー | 操作 |
|------|------|
| `Fn` + `;` | ← (左矢印) |
| `Fn` + `'` | → (右矢印) |
| `Fn` + `[` | ↑ (上矢印) |
| `Fn` + `/` | ↓ (下矢印) |
| `Fn` + `K` | Home |
| `Fn` + `,` | End |
| `Fn` + `L` | Page Up |
| `Fn` + `.` | Page Down |

:::note info
矢印キーの位置（`;` `'` `[` `/`）は最初戸惑いますが、1週間も使えば手が覚えます。ホームポジションから手を離さずに移動できるのが快適です。
:::

## Bluetooth操作（HYBRID/HYBRID Type-S）

HHKB HYBRIDシリーズはBluetooth接続に対応しています。最大4台のデバイスとペアリング可能です。

### ペアリング・接続切り替え

| キー | 操作 |
|------|------|
| `Fn` + `Q` | ペアリング待機モードに入る |
| `Fn` + `Ctrl` + `1`〜`4` | デバイス1〜4とペアリング/切り替え |
| `Fn` + `Ctrl` + `0` | USB接続に切り替え |
| `Fn` + `X` | ペアリングモードをキャンセル |

### ペアリング削除

| キー | 操作 |
|------|------|
| `Fn` + `Q` → `Fn` + `Ctrl` + `BS` + `1`〜`4` | 指定デバイスのペアリングを削除 |
| `Fn` + `Z` + `BS` | 全ペアリング情報を削除 |

### OS切り替え

| キー | 操作 |
|------|------|
| `Fn` + `Ctrl` + `W` | Windowsモード |
| `Fn` + `Ctrl` + `M` | Macモード |

## DIPスイッチ設定

HHKBにはDIPスイッチがあり、キー配列をカスタマイズできます。

| SW | ON | OFF |
|----|-----|-----|
| SW1 | Macモード | Windows/PCモード |
| SW2 | BackspaceとDelの入れ替え | 標準 |
| SW3 | Delをバックスペースに | 標準 |
| SW4 | 左◇をFnに | 標準 |
| SW5 | ◇をAltに | ◇は◇のまま |
| SW6 | 省電力オフ | 省電力オン |

:::note warn
機種によってSW設定が異なる場合があります。公式マニュアルをご確認ください。
:::

## HHKB Keymap Toolでのカスタマイズ

HHKB Professional HYBRID以降では、専用ツール「HHKB Keymap Tool」でキーマップをカスタマイズできます。

- **公式ダウンロード**: https://happyhackingkb.com/download/
- 最大4レイヤー（プロファイル）を設定可能
- F20〜F24キーも割り当て可能

## まとめ

HHKBを使いこなすポイント：

1. **Fnキー組み合わせを覚える** - 特に矢印キー（`;` `'` `[` `/`）とPage Up/Down
2. **Bluetooth操作を習得** - `Fn+Q`でペアリング、`Fn+Ctrl+数字`で切り替え
3. **OSショートカットと組み合わせる** - `Win+V`のクリップボード履歴は必須

最初は戸惑いますが、1週間も使えばホームポジションから手を離さない快適さが病みつきになります。
